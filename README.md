# ⚡ Kavya Jangid | B.Tech ECE 1st Year Portfolio Website

A modern, responsive, circuit-themed personal portfolio built with **HTML5**, **CSS3**, and **Vanilla JavaScript** specifically tailored for a **1st Year B.Tech Electronics and Communication Engineering (ECE)** undergraduate.

---

## 🌟 Key Features

1. **Hardware + Code Persona**:
   - Tailored for a freshman engineering student exploring the intersection of electronics, microcontrollers (Arduino, ESP8266), C/C++ programming, and digital logic.
2. **Responsive Design**:
   - Mobile-first, fully responsive across smartphones, tablets, laptops, and ultra-wide screens.
3. **Interactive Features (Vanilla JavaScript)**:
   - **Dark / Light Mode**: Seamless theme toggle with local storage persistence.
   - **Hero Typing Effect**: Smooth dynamic typing cycling through ECE-related interests.
   - **Project Filtering**: Instant category tabs (*All*, *Hardware & IoT*, *Software & C++*, *Web & Portfolios*).
   - **Contact Form Validation**: Real-time error handling with interactive simulated submission and toast alerts.
   - **Active Navigation Spy**: Automatically highlights current navbar link on scroll.
4. **No Heavy Framework Dependencies**:
   - Built purely with standard semantic HTML5, clean modular CSS3 with custom variables, and vanilla ES6 JavaScript. Uses lightweight Google Fonts and Remix Icons CDN.

## 📂 Project Structure

```
My portolio/
```

---

## 🚀 How to Run & View

1. Simply double-click **`index.html`** or right-click and select **"Open with Chrome"** (or Edge/Firefox).
2. Or use the VS Code extension **Live Server** to preview live reload changes.

---

## 🛠️ Easy Customization Guide

- **Name & Title**: Customize your name, bio, and title in `index.html`.
- **Social Links**: Update your actual GitHub, LinkedIn, LeetCode, and email links in the Hero and Contact sections.
- **Projects**: Add or edit projects inside `<div class="projects-grid">` in `index.html`.
- **Colors & Themes**: Modify CSS variables inside `:root` and `[data-theme="light"]` in `style.css`.
